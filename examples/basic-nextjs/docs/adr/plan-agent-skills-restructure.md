# Plan: Cross-agent skills restructure

Implements [ADR 0007](0007-cross-agent-skills-layout.md). All paths are relative to `examples/basic-nextjs/` unless noted. Each phase is one PR, independently shippable and revertable.

## Target layout

```
examples/basic-nextjs/
├── AGENTS.md                         # slim always-on core (hand-written)
├── CLAUDE.md                         # "@AGENTS.md" only
├── .agents/
│   ├── mcp.json                      # canonical MCP servers
│   └── skills/<name>/{SKILL.md, scripts/, references/, assets/}
├── tools/agents/
│   ├── sync.mjs  lint.mjs  eval.mjs  validate-components.mjs
│   ├── setup.sh  setup.ps1  setup.cmd
│   └── evals/routing.yaml
├── docs/ai/                          # project knowledge & state only
│   ├── config/  manifests/  catalog/  reference/  designs/
│   └── demos/ themes/*/              # gitignored outputs
│
│  GENERATED by `npm run agents:sync` (committed, never hand-edited)
├── .claude/skills/<name>/SKILL.md    .claude/agents/<name>.md
├── .cursor/skills/<name>/SKILL.md    .cursor/rules/*.mdc
├── .mcp.json  .cursor/mcp.json  .pi/mcp.json
```

npm scripts: `agents:sync`, `agents:sync:check`, `agents:lint`, `agents:eval`, `agents:validate`, `agents:setup`.

## Canonical frontmatter

```yaml
---
name: sitecore-build-demo                 # == folder name
description: <what + "Use when …">        # ≤1024 chars
disable-model-invocation: true            # command-only skills only
metadata:
  subagent: true                          # also emit .claude/agents/<name>.md
  owner: demo-builder
---
```
