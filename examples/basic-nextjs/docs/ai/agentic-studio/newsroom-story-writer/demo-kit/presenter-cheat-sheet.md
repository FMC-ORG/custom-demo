# Presenter cheat sheet: HEINEKEN Newsroom Story Writer

**Every scenario:** Agentic → Chat → **new chat** → agent **HEINEKEN Newsroom Story Writer** → attach the file → type `Write a news story from the attached press release.` Answer by the **meaning** of the option (letters can change). When unsure, take **(Recommended)**.

## Scenario 1: Global newsroom (`scenario-1-global-going-out-study.docx`, fictional)

| Question | Answer |
|---|---|
| Which newsroom? | **`heineken`**, global (Recommended) |
| Image | **No image** |
| "…cannot really enjoy a night out without a cold beer…" | **Leave it out** |
| "Even younger students say they cannot wait until they are old enough…" | **Leave it out** |
| Bopha Lim: "…the best investment a venue can make." | **Keep only as an attributed verbatim quote** |
| Draft review | **Write it** |

Point out: HEINEKEN Cambodia and Heineken® 0.0 corrected · ranges kept · research method kept · Khmer quote translated · "-ENDS-", download link, About and contacts dropped · SEO title ends `| The HEINEKEN Company`.
